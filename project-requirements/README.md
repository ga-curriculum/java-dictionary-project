## Overview

Java Dictionary Project

The first project is to build a console-based dictionary application that allows users to perform various operations on a dictionary of words and their definitions. The application will utilize the concepts learned in Java, such as data types, variables, control flow, loops, methods, scopes, arrays, ArrayLists, Object-Oriented Programming (OOP), exception handling, and file I/O.

The dictionary application will be a command-line interface (CLI) program that runs in the console without a graphical user interface (GUI). Users will interact with the application by typing commands and receiving text-based output.

***You will work individually on this project***.

> ❗️ As a reminder, General Assembly has a zero-plagiarism policy. ***Your project's code must be substantially yours***. Do not copy code from similar projects or other sources. However, using code from the internet to accomplish generic tasks is okay - for example, a line of code that replaces a character at a specific position in a string.

A printable version of the project requirements can be found [here](./assets/project-requirements.pdf).

## Technical requirements

### MVP

> ✅ Any items marked incomplete in this section will require you to use your one redo to re-submit them. Your app must fulfill the below requirements.

- Load a dictionary from a text file containing word information.
- Save the updated dictionary back to the text file.
- Allow users to do the following:
    - Add new words and definitions to the dictionary.
    - Remove words and their definitions from the dictionary.
    - Search for words and display their definitions.
    - Update the definitions of words.
    - Close the application.
    - Display a history of past user actions. 
- There is a runnable JAR file that allows users to download and run the project.

Additional requirements - choose and implement 4 of the following user options:
- Find all words starting with a given string.
- Find all words ending with a given string.
- Find all words containing a given string.
- Find all words where the definition contains a given string.
- Add additional definitions (secondary, tertiary, etc.) to a word.
- Display an alphabetically sorted list of all words.

### Code convention

> ✅ More than two items marked incomplete in this section will require you to use your one redo to re-submit them. If two or fewer items are marked incomplete, the project is considered passing. Your app must fulfill the below requirements.

- The files in the app are organized following the conventions demonstrated in lectures.
- The code in the app adheres to coding conventions covered in lessons, like using plural names for arrays.
- The app does not contain dead code, commented-out sections, or console logs.
- The app is appropriately broken down into classes and functions with distinct roles.
- The app can be used without encountering errors, and appropriately uses error handling.
- The app is coded using proper indentation.
